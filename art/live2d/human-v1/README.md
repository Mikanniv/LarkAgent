# 云雀坐姿人型 · 对称眼型修正版 v3

最新可编辑工程为 [云雀-对称眼型.cmo3](云雀-对称眼型.cmo3)，制作工程与历史为 [云雀-对称眼型.psd2live](云雀-对称眼型.psd2live)。`云雀.cmo3` 是最新工程的副本。`final-v3/runtime/` 保存网页缓存、原生 MOC3、model3 JSON 和一张 2048 像素图集；`final-v3/source/` 保存打包后的 Cubism 工程与导出报告。

本轮针对两眼比例与睫毛弧线不一致，改为左右眼复用同一份眼白、虹膜、睫毛素材及网格。眼白和睫毛按倾斜的面部中线镜像放置，虹膜保持同一高光方向；保留原有转头、瞳孔移动与眨眼绑定。中性姿态的放大渲染中，可见虹膜分别为 154×177 与 154×176 像素；这一测量只对应该预览比例，不代表各角度的投影轮廓完全相同。

网页运行模型直接复用 v2 原图集，图集文件逐字节相同，头发和身体没有重新缩小。v3 的可编辑 CMO3 为保证独立的左右眼图层位置，从图集重建了画布分辨率的图层切片；高倍率编辑时不应把这些切片当作原始高清素材。高清原始图层及用户已确认可在官方 FREE 版打开、保存的 [云雀-FREE修正版.cmo3](云雀-FREE修正版.cmo3) 均保留；`云雀.psd2live` 与 `云雀-修正版.psd2live` 仍是 v2。

形象拆成身体、脸、前后发、发饰、左右眼白、左右虹膜、左右睫毛、眉毛与微笑线，共 13 层。后发和脸部补齐了遮挡区域。头部 X/Y、眼球 X/Y 与左右眨眼已绑定；当前网页保留坐姿身体和微笑，不驱动语音口型。独立桌宠的鸟型和 Q版小人未在本轮制作动态模型。

网页通过 `static/character.js` 驱动网格模型 `static/live2d/human/yunque.p2lrt`，可在设置中关闭跟随。这个缓存格式与原生 Cubism 导出使用同一套关键形，播放器是独立实现，不是官方 Cubism SDK。界面不读取屏幕或摄像头。

验证记录在 `qa/`：v3 已核对九向朝向、眨眼、左右虹膜尺寸及网页实际渲染；三个右眼网格经过原生文件往返读取，位置误差为 0 像素。v3 仍为 13 个网格、20 个参数、18 个弯曲变形器与 1 个旋转变形器，一张 2048 图集；所有弯曲变形器分割数不超过 9×9，单对象直接绑定最多两个参数。v2 的三个超限变形器已调整，用户确认官方 Cubism Editor 5.3.04 FREE 打开与保存无超限提示。v3 新眼型工程的官方编辑器打开与保存尚未另行人工复核；导出报告如实记录图层切片重建，不能把运行时无损导出等同于高清源图层无损。

分层补绘使用内置图像生成工具；参考原画为 `static/branding/characters/human-seated.png`，原画保留不变。初次分层提示词见 [generation-prompts.json](generation-prompts.json)，v2 眼白及睫毛补绘见 [eye-correction-prompts-v2.json](eye-correction-prompts-v2.json) 与 [lash-correction-prompt-v2.json](lash-correction-prompt-v2.json)，补绘部件保存在 `layers/`。v3 没有分别生成两只眼，而是复用同一眼型。`source.json` 与 `yunque-human-artwork-draft.psd` 是早期底稿，不是最终绑定工程。`release-v1/` 是参数精简失败的试验输出，不能使用；其他带 draft 的文件供回溯。`paired-eyes-v3.cmo3` 是打包前的两图集底稿，继续编辑请用上述中文命名的最新工程。

制作工具为开源 PSD2Live 3.5.2，工程生成工具保存在本地忽略目录 `desktop/.local/tools/`。只在网页分发其 MIT 许可的独立播放器与运行库，许可证保存在 `static/live2d/runtime/`。未下载或捆绑官方 Cubism SDK。
