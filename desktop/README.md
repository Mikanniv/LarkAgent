# 云雀桌面壳 v0.1

本版提供气泡主页、聊天布局、透明置顶桌宠、鸟型 / Q版小人切换、拖动和隐藏。网页坐姿人型已有分层转头和眨眼，独立桌宠的鸟型与 Q版小人仍使用静态立绘。尚未接入屏幕捕获或音乐平台。

## 在 Mac 上启动

第一次需要 Node.js 22.12 或更新版本。在本目录执行：

```sh
npm install
npm start
```

也可以双击本目录的 `启动云雀.command`。首次运行会从官方来源下载 Electron。桌面壳默认连接本机 `http://127.0.0.1:8001` 的云雀后端；后端未启动时，界面和桌宠仍可体验，聊天显示连接状态。

启动后，既可以在桌面程序内使用主页，也可以从浏览器打开 `http://127.0.0.1:17643`。现有网页通过仅监听 `127.0.0.1:17643` 的连接控制桌宠。浏览器可能询问访问本地网络的权限，需要允许后才能连接本机桌宠。

- 主页「显示桌宠」可以召出桌宠，再点一次隐藏。
- 右键 / Mac 触控板两指点按，选择鸟型、Q版小人或隐藏。
- 按住角色拖动。透明区域允许点击下方应用。
- 「设置 → 视线跟随鼠标」控制网页坐姿人型的转头和瞳孔跟随；独立桌宠的两种形态仍是静态。
- 关闭主窗口后，桌宠继续陪伴；从菜单栏图标重新打开或退出。
- 形态、位置、跟随偏好自动保存；重新启动后，桌宠等待用户召出。

## 配置

可通过启动环境变量指定：

| 变量 | 用途 |
| --- | --- |
| `YUNQUE_API_BASE` | 桌面壳的后端地址，默认 `http://127.0.0.1:8001` |
| `YUNQUE_WEB_ORIGINS` | 额外允许连接桌面壳的网页来源，逗号分隔，填写完整 origin（协议、主机和端口） |
| `YUNQUE_USER_DATA` | 可选的运行数据目录；开发验证使用本目录 `.local/` |

默认允许正式域名 `https://lark.irises.me`、`https://worker.lark.irises.me` 和本机 `8001`、`4173`、`17643` 端口。其他部署域名需要显式加入 `YUNQUE_WEB_ORIGINS`。浏览器中的「打开云雀桌面」使用 `yunque://show-pet`；首次使用须先运行本机程序以完成协议注册。

## 检查

```sh
npm run check
npm test
```

主程序只读取鼠标坐标，不读取屏幕图像。桌面窗口使用隔离的预加载接口，关闭 Node 网页集成；本地控制连接要求受信任来源与会话令牌。屏幕共享请求被拒绝。

## 素材

角色由内置图像生成工具根据本次确认的设定生成，位于 `../static/branding/characters/`。坐姿主形象、人型 Q 版和自然鸟型均保留蓝色及金黄色眼睛的识别特征。

坐姿人型使用 13 个独立图层和网格关键形，支持朝左右转头、抬头、低头、瞳孔跟随及眨眼。鼠标方向驱动头部 X/Y；不叠加斜向摇头。设置中的「查看形象」可预览三种形态，鸟型和 Q版小人明确标为静态。

制作工程见 [形象工程说明](../art/live2d/human-v1/README.md)。浏览器播放器及 WebAssembly 运行库为 PSD2Live 的独立 MIT 模块，许可证随文件保存在 `static/live2d/runtime/`；未包含官方 Cubism Core。最新 v3 统一了左右眼的基础素材和网格。v2 的官方 FREE 版打开与保存已由用户确认，v3 新眼型工程尚未另行人工复核。
