# AI记日期切换调试小站

这是一个独立调试站，不复用正式后端接口，也不读写正式 `memories/chat.sqlite3`。

## 启动

```bash
python3 debug_diary_lab/app.py
```

默认地址：

```text
http://127.0.0.1:8011
```

## 测试方式

1. 把当前日期设为 `2026-03-19`。
2. 在聊天框发几句话。
3. 点击“切到选中日期并触发生成”，把日期改成 `2026-03-20`。
4. 点击日历里的 `2026-03-19`，查看 3 月 19 日 AI记是否生成。

## 数据隔离

调试数据只写入：

```text
debug_diary_lab/debug_diary.sqlite3
```
