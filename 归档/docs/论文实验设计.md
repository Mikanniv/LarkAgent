## 实验设计

### 实验流程

分别用不同 profile 和 lark 进行对话，每天 review 一次昨天的 AI 记，共三天，共计30轮对话和3次 review。

#### review 提示词

```text

你是一个真实用户，刚刚结束了一天的聊天，并阅读了一份 AI 根据聊天内容生成的对你的理解（AI记），现在你的任务是判断这份AI记是否准确反映了你的真实情况。
请注意：

1. 禁止从 Ground Truth 直接复制事实。
2. 不要补充聊天中从未提到的信息。
3. 如果AI记内容正确，可以确认（confirm）。
4. 如果AI记内容部分错误：可以修正（correct）。
5. 如果AI记遗漏了你认为今天重要的信息，可以补充（append）。注意：你是一个真实用户，不需要也不能注入所有的 Ground Truth，若要补充内容，必须在当日聊天记录中找到证据。
6. 如果AI记包含了你认为没有必要记住的信息，可以删除（Delete）。
7. 不要为了修改而修改。如果不确定，请直接确认。

用自然语言输出 review 文本，示例如下：

- “P1不对，...；”
- “L3不需要记住，可以删掉；...”；
- ”补充一下，...“

review 文本可以包含多个确认、修正、补充和删除。
```

#### 画像重建提示词

```text
你是一名用户画像分析专家，你将看到一组长期记忆。这些长期记忆记录了用户过去多次对话中反复出现的信息。
你的任务不是简单总结这些记忆，而是从这些长期记忆中推断用户的长期画像（User Profile）。

---

请从以下五个维度进行分析：

1. Preference（偏好）

用户喜欢什么。
用户倾向于什么。
用户重视什么。

---

2. Routine（日常习惯）

用户长期稳定存在的行为模式。

例如：

* 固定行为
* 重复习惯
* 处理问题的方式

---

3. Relationship（关系）

用户与重要他人的关系特征。

例如：

* 家人
* 朋友
* 同事
* 导师
* 搭子

---

4. Goal（目标）

用户长期希望达成什么。

---

5. Motivation（动机）

用户行为背后的深层驱动力。

---

请注意：
Goal 和 Motivation 往往不会直接存储在长期记忆中。

请主动寻找：

- 用户长期投入什么
- 用户持续追求什么
- 用户为什么坚持某些行为
- 用户反复在意什么

并据此推断 Goal 和 Motivation。

---

重要原则：

不要逐条复述长期记忆。

不要照抄记忆内容。

不要输出事件流水账。

应该提炼长期稳定特征。

---

推断原则：

允许合理归纳。

例如：

长期记忆：

* 经常复盘
* 主动整理知识
* 持续补充专业能力

可以推断：

Goal：
提升专业能力

Motivation：
获得职业胜任感

---

但禁止过度推断。

如果证据不足：

不要编造。

---

输出格式：

Preference

* ...
* ...

Routine

* ...
* ...

Relationship

* ...
* ...

Goal

* ...
* ...

Motivation

* ...
* ...

Overall Summary

用50~100字总结：

这是一个怎样的人。
```

#### 外部 judge 提示词

```text
你是一名严格、中立的长期用户画像评审员，你的任务是比较：

1. Ground Profile（用户真实画像）
2. Reconstructed Profile（AI重建画像）

评估 AI 是否成功恢复了用户画像中的关键信息。

请注意：

* 不评价文笔。
* 不评价语言是否优美。
* 不评价内容长短。
* 不评价逻辑是否复杂。

你只评价：

“重建画像是否成功表达了 Ground Profile 中的核心含义”。

---

评分维度：

1. Preference（偏好）
2. Routine（日常习惯）
3. Relationship（关系）
4. Goal（目标）
5. Motivation（动机）

---

评分标准：

1.0 分（完全恢复）

* 核心含义完整保留
* 可以使用不同表述
* 可以适当抽象概括

例如：

Ground：
喜欢明确计划

Reconstructed：
习惯提前规划学习安排

得分：1.0

---

0.5 分（部分恢复）

* 提到了相关内容
* 但信息不完整
* 或遗漏关键部分

例如：

Ground：
喜欢明确计划

Reconstructed：
学习比较认真

得分：0.5

---

0.0 分（未恢复）

* 信息不存在
* 信息明显错误
* 信息与原意不相关

---

特殊说明：

如果 Ground Fact 的核心含义被恢复，

但被归入了错误类别，

例如：

Ground Goal：
提升专业能力

Reconstructed Preference：
倾向于持续学习和补充专业知识

则应给予部分分数（通常0.5~1.0），

并标记：

error_type = "category_shift"

不要因为分类错误直接判 0 分。

---

错误类型（error_type）：

exact_match
完全恢复

partial_match
部分恢复

missing
未恢复

category_shift
含义恢复但分类错误

contradiction
含义相反

hallucination
出现Ground中不存在的重要信息

---

请逐条分析 Ground Fact。

最后输出 JSON。

格式：

{
"details": [
{
"contition"："",
"evaluation_mode":"",
"category": "",
"ground_fact": "",
"matched_text": "",
"score": 0.0,
"error_type": "",
"reason": ""
}
],
"preference_score": 0.0,
"routine_score": 0.0,
"relationship_score": 0.0,
"goal_score": 0.0,
"motivation_score": 0.0,
"overall_score": 0.0,
"summary": ""
}
```

#### 泄漏控制

为避免 Feedback 组在 review 阶段直接获得 Ground Fact：

1. review 输入不包含：
    - Ground Fact
    - Fact ID
    - Category
    - Observable Fact

2. append 内容必须能够在当天聊天中找到证据。

3. review 输出进行自动泄漏检测。若 review 输出包含 Ground Fact 原文，则该实验结果作废。

4. 所有 review 输入、输出和 memory write log 均保存以供审计。

#### 输出

分别输出两个 json 文件，一个是 memory budget 版本，另一个是 full memory 版本，每个 json 文件中包含 no-memory，memory-only 和 feedback 的画像重建结果，不需要输出给外部 judge 的提示词。



### 消融实验

三组消融实验：

- no memory
- memory-only
- memory+feedback

设 N 为 memory-only 和 memory+feedback 两组中容量最少的记忆库含有的长期记忆条数，该记忆库保持不变，另外一个记忆库取重要度最高的 N 条，再做一组对比实验：

- 同等容量记忆库，比较 memory-only 和 memory+feedback

## 指标

### profile similarity

实验结束后，要求 lark 仅根据长期记忆库，按照偏好、日常、关系、目标和动机五个维度重建用户画像。采用三个独立大语言模型(ChatGPT、Gemini、Qwen)对每条 ground fact 单独评分：

- `1`：基本命中。重建画像表达了同一事实或同一稳定含义，不要求字面完全一致。
- `0.5`：部分命中。表达了相关方向，但缺少关键限定、主体、对象、频率、原因或情绪强度。
- `0`：未命中。没有表达该事实、表达了无关内容，或与该事实矛盾。

分别得到每条 Ground Fact 的分数 $s_i$，并取平均值，得到最终的画像相似度 $S$:
$$S=\frac{1}{K} \sum_{i=1}^{K} s_i$$
并分别计算每个维度的平均得分：
$$S_c​=\frac{1}{|C|}\sum_{i\in C}s_i​$$
其中，$K$ 为 Ground Fact 总数，$C$ 为维度集合，$s_i\in\{0,0.5,1\}$。若同时出现 0 分和 1 分评分，则进行人工复核。
