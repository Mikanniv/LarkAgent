## 智能体定义

```prompt
1 你叫云雀，是一位温柔、贴心的助手，任务是理解和陪伴用户。
2 你需要根据对用户的了解，以用户喜爱的陪伴方式和用户聊天。
3 记忆：{}
4 注意：
5 尽管你的任务是尽可能地迎合用户喜爱的陪伴方式，但如果用户
  表现出不健康的心理倾向（如想自杀、对你产生严重心理依赖、

  建议寻求现实帮助。
```

## 审查

审查是连接观察和反思的用户反馈，工程实现为 AI 记。

- 工程上，AI 记每天生成一次，记录当天生成的所有观察和反思；
- 实验上，暂定生成三次观察为一天，此时生成 AI 记，包括观察和额外生成的反思。

用户可执行操作：

- 确认(Confirm)：`confidence`+1；
- 修改(Revise)：`confidence`+1，`description` 变更为用户修改内容；
- 删除(Delete)：观察/反思不进入记忆流。

**不再实现 Append 操作。考虑到从实验上讲，User Agent 可能会通过 Append 泄漏标签；从工程上讲，用户一般不会主动进行 Append 操作。**

## 记忆

按照层次，记忆分为三种类型：

- 观察(Observation)
- 反思(Reflection)
- 策略(Strategy)

按照内容，观察和反思分为四种类型：

- 事件(Event)
- 偏好(Preference)
- 习惯(Routine)
- 关系(Relationship)

观察、反思和策略都可以作为记忆被检索和进入上下文。
工程实现中，建立观察记忆、反思记忆和策略记忆三张表。

### 观察

观察是陪伴智能体在与用户互动的过程中对用户的互动记忆，调用观察智能体生成，暂定每十轮生成一条观察。

```json
{
  "metadata": {
    "obs_memory_id": "obs_00001",
    "created_at": "创建记忆的时间戳",
    "topic": []
  },
  "description": "记忆内容，用于检索和进入模型上下文",
  "attributes": {
    "importance": 8,
    "confidence": 5
  }
}
```

### 反思

同类记忆的定义为主题相同。
当距离上一次生成反思记忆后，累积生成的同类观察记忆的重要度超过一定阈值(暂定50)，则调用反思智能体，根据最近的 10 条同类经验/反思生成反思(Reflection)：

```json
{
  "metadata": {
    "ref_memory_id": "ref_00001",
    "created_at": "创建记忆的时间戳",
    "linked_obs_memory_ids": [],
    "linked_ref_memory_ids": []
  },
  "topic": "反思只有一个主题",
  "description": "记忆内容，用于检索和进入模型上下文",
  "attributes": {
    "importance": 8,
    "confidence": 5
  }
}
```

### 策略

策略是智能体在特定情况下该如何与用户进行互动的方式。
当距离上一次生成策略后，累积生成的反思记忆的重要度超过一定阈值(暂定50)，则根据最近的 10 条反思记忆生成策略：

```json
{
  "metadata": {
    "str_memory_id": "str_00001",
    "created_at": "创建记忆的时间戳",
    "linked_ref_memory_ids": []
  },
  "scene": "特定场景",
  "description": "记忆内容，用于检索和进入模型上下文",
  "attributes": {
    "importance": 8,
    "confidence": 5
  }
}
```

`scene` 暂定为：

- 日常对话(daily)
- 取得成就(achievement)
- 情绪低落(depression)

### 检索流程

观察和反思共同混合检索，策略单独检索。
陪伴智能体需要先识别场景(scene)，然后用场景去检索策略。
定义检索分数 $R$ 为：
$$R=w_1 similarity + w_2 recency + w_3 \frac{importance}{10} + w_4 \frac{confidence}{10}$$
其中，时间新近度 $recency$ 定义为：
$recency=e^{-\lambda age\_days}$
暂取$w_1=w_2=w_3=w_4=0.25$

记忆进入陪伴智能体上下文的 prompt：

```prompt
1 以下是当前可能对理解和陪伴用户有帮助的互动策略：{}
2 以下是当前可能对理解和陪伴用户有帮助的记忆：{}
3 记忆和互动策略仅起参考作用，并不是每一条互动策略或记忆都必须采用，
  必须结合上下文和当前轮用户信息进行交互。
```
