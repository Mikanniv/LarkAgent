## 长期记忆
### 数据库
使用ChromaDB，每条记忆的结构如下：
- `document`
	- 记忆的自然语言内容，用于语义检索
- `metadata`
	- `date`：日期（如2026-04-28）
	- `timestamp`：具体时间（如2026-04-28T16:45:25+08:00）
	- `user`：记忆署名
		- `user`
		- `ai`
	- `user_id`：用户id，`user`字段为`ai`时可省略
	- `type`：类型
		- `event`
		- `routine`
		- `preference`
		- `relationship`
		- `summary`：AI总结，展示为AI记内容
	- `source`：记忆来源
		- `conversation`
		- `diary_user`
		- `inference`
	- `has_emotion`：是否有情绪状态。该字段为`false`时，`valence`和`arousal`字段可省略
	- `valence`：效价
	- `arousal`：唤醒度
	- `confidence`：置信度
	- `importance`：重要度，决定是否遗忘或加强记忆，范围为0～1浮点数
	- `text`：是否有文本模态
	- `audio`：是否有音频模态
	- `video`：是否有视频模态
### AI记：数据增强策略
#### AI记
在每天结束时，AI会根据今日和用户的互动和用户日记，自动总结一份**AI日记**，用户可查看AI日记并进行修改。例如：

> [!example]
> AI记：“今天用户不太高兴，我采取了直接询问缘由并给出建议的行动，但用户似乎并没有感到好转。“
> 用户修改：”其实我当时更偏向于生气了，并且我希望你先直接安慰我的情绪，而不是立刻问我怎么了并让我去干什么。“

#### 记忆写入
当agent认为有必要写入记忆时，将会根据记忆类型、来源等数据，结合时间上距离该对话最近的几次多模态情感分析结果计算$importance_0$。
`type`字段值决定了$importance_0$的基础值：
```python
TYPE_BASE = {
    "preference": 0.75,
    "relationship": 0.70,
    "routine": 0.65,
    "event": 0.60,
    "summary": 0.55,
}
```
`source`字段值修正：
```python
SOURCE_BONUS = {
    "diary_user": 0.05,
    "conversation": 0.03,
    "inference": -0.05,
}
```
当决定写入时，`valence`和`arousal`字段值将取最近三次情感计算的平均值，若不足三次，则使用已有的平均值。该设计用于降低单次输入噪声，使长期记忆记录的是写入时刻的情绪。
`confidence`字段值修正：$$bonus_{confidence}=0.18 \times (confidence - 0.5)$$
考虑到`valence`和`arousal`字段值已用于计算$confidence$，故不再参与修正$importance_0$。
AI记用户确认修正：$$bonus_{confirmation}=
\begin{cases}
	0.05,\qquad 用户确认日记准确 \\
	0.08,\qquad用户修改了日记 \\
	0.00,\qquad用户没有反馈
\end{cases}$$
#### 记忆合并和修正
用户可直接确认AI记准确或者对AI记进行修改后再确认。确认后，AI将根据用户的反馈进行记忆强化或修正。
> [!example]
> “用户强调在ta情绪低落时先安慰ta的情绪，而不是强行让ta先解决问题，我会把这条用户偏好加入记忆库并置高重要度。”
> “用户对我的日记直接确认，说明我的认知和理解是准确的，我可以提高相关记忆的置信度。”

**通过这样的人机交互形式，AI将产生“越用越懂你”的个性化进化。**
#### 记忆遗忘
记忆的重要度$i$将随着时间推进而逐步下降，衰减函数为：$$i=i_0 \times e^{(i_0-1)\Delta t}$$
其中，$i_0$∈\[0,1] 表示初始重要度，$\Delta t$表示距写入时刻的时间间隔。
该函数保证记忆重要度随时间下降，且初始重要度越高，衰减速率越慢，从而使高重要度记忆保留更久。
#### 记忆召回
用户输入后，模型将检索记忆库中的记忆，并通过公式计算召回分数：$$s=\alpha (1-d)+ \beta i+ \gamma r$$
其中，$d$∈\[0,1] 为归一化语义距离，$r$∈\[0,1] 为时间新近度，
$\alpha$、$\beta$、$\gamma$为可调权重，且$\alpha + \beta + \gamma = 1$
最终召回得分最高的 top-k 条记忆，当前设定 k=3。
## 模型架构
### 特征提取工具
SIMS数据集官方给出的特征如下：
- **文本 (Text)**：
    - 对所有视频进行人工转录。
    - 使用**预训练的中文 BERT-base** 获取词向量，每个词被表示为 **768 维**的向量。
- **音频 (Audio)**：
    - 使用 LibROSA 工具包提取 22050Hz 的声学特征。
    - 最终提取出 **33 维**帧级特征，包括对数基频 (log F0)、20 维梅尔频率倒谱系数 (MFCCs) 和 12 维常 Q 谱图 (CQT)。
- **视觉 (Vision)**：
    - 以 30Hz 的频率提取视频帧。
    - 利用 **MTCNN 算法**进行人脸检测与对齐。
    - 使用 **OpenFace 2.0** 工具包提取 68 个面部关键点、17 个面部动作单元 (AU)、头部姿态及视线方向，共计 **709 维**特征。

考虑到该项目实时性较强，视觉将改为使用**MediaPipe**提取特征，项目早期优先考虑实现以下特征：
- smile
	- 微笑强度
	- $smile=mean(mouthSmileLeft,mouthSmileRight)$
- frown
	- 皱眉强度
	- $frown=mean(browDownLeft,browDownRight)$
- mouthOpen
	- 嘴巴张开程度
	- mouthOpen = mouthOpen_blendshape
- browRaise
	- 眉毛上抬程度
	- browRaise = mean(browOuterUpLeft, browOuterUpRight, browInnerUp)
- eyeWiden
	- 眼睛睁大程度
	- eyeWiden = mean(eyeWideLeft, eyeWideRight)
- jawOpen
	- 下颌张开程度
	- jawOpen = jawOpen_blendshape
- cheekRaise
	- 面颊上提程度
	- cheekRaise = mean(cheekSquintLeft, cheekSquintRight)
- squint
	- 眯眼程度
	- $squint=mean(eyeSquintLeft, eyeSquintRight)$
- blink
	- 眨眼频率
	- $blink = mean(eyeBlinkLeft, eyeBlinkRight)$
### 多模态情感分析模型
#### 输入
- **文本**
- **音频：提取声学特征。考虑到当用户选择开启麦克风时，一般是用于语音交流。所以在文本模态缺失时，若音频模态存在，模型将识别语音文本，并用语音文本替代用于文本模态输入。**
- **视频**
#### 模型
使用self_mm作为情绪提取器，分别得到单模态得分和总得分。
#### 输出
将self_mm输出的单模态得分和多模态融合得分、MediaPipe识别的表情分数经过一系列映射，最终输出`valence`、`arousal`、`confidence`和离散情绪标签。设$f$为多模态融合得分，$t$、$a$、$v$分别为文本、音频和视频模态得分，则映射规则如下：
##### valence
我们定义预测的情绪总得分$\hat{f}$为
$$\hat{f}=w_f f+w_t t+w_a a+w_v v$$
其中，$w_f$、$w_t$、$w_a$、$w_v$是归一化的可学习参数：
$$w_i=\frac{e^{w_i}}{\sum_{j}^{} e^{w_j}} $$
归一化后满足以下条件：
$$\begin{cases}
	w_i \ge 0 \\
	\sum w_i=1
\end{cases}$$
我们用$\hat{f}$近似表示$valence$：
$$V_0 \approx \hat{f} $$
对$V_0$应用非线性归一化，使数值更稳定：
$$V_1=tanh(V_0)$$
定义$\Delta V$为表情偏移量：
$$\Delta V=0.22 \times smile+0.10 \times cheekRaise-0.22 \times frown-0.08 \times squint$$
最终，$valence$表示为：
$$V=clamp(V_1+\Delta V,-1,1)$$
其中，`clamp(value,min,max)`函数表示将$value$截断到$(min,max)$区间。
##### arousal
由于 Self-MM 输出主要反映情绪极性，所以用$t$、$a$、$v$的绝对值作为情绪强度的近似估计，并结合视觉表达特征进行修正：
$$\Delta A=clamp(0.25 \times mouthOpen+0.3 \times jawOpen +0.18 \times eyeWiden+0.14 \times browRaise+0.13 \times squint+0.10 \times blink,0,1)$$
$$A_0=0.45 \times tanh(|t|)+0.20 \times tanh(|a|)+0.10 \times tanh(|v|)+0.25 \Delta A$$
$$A=clamp(0.1+A_0+\Delta A)$$
##### confidence
$$availability=0.50 \times text+0.35 \times audio+0.15 \times video$$
$$agreement=clamp(1-0.40 \times abs(f-t)-0.3 \times abs(f-a)-0.3 \times abs(f-v),0.0,1.0)$$
$$strength=clamp(0.55|V|+0.45A,0,1)$$
$$confidence=clamp(0.4 \times availability+0.3 \times agreement+0.3 \times strength,0,1)$$
其中，$text$、$audio$、$video$分别表示该模态是否存在。
##### 离散情绪标签
```python
if valence >= 0.60 and arousal >= 0.50:
    label = "兴奋"
elif valence >= 0.35:
    label = "高兴"
elif valence <= -0.60:
    label = "愤怒"
elif valence <= -0.35:
    label = "紧张"
elif valence >= 0.2 and arousal < 0.50:
    label = "平静"
elif valence <= -0.20:
    label = "低落"
else:
    label = "中性"
```
#### 频率
当满足以下一种条件时，模型会计算情感：
- 用户有聊天框文本输入时，立即进行一次情感计算并返回结果给文本模型，文本模型进行回应。
- 用户有音频输入且ASR结果有清晰语义，立即进行一次情感计算并返回结果给文本模型，文本模型进行回应。
- 当用户无任何文本输入（包括聊天框文本输入和ASR清晰语义文本输入）时，当距离上一次情感计算的时间超过15s后，每隔10s定期进行一次情感计算并保存。
### 文本输出模型
#### 底层模型
- 使用kimi-k2.5模型
#### 主动回应机制
当满足以下一种触发原因时，模型会触发主动回应机制：
- 用户120s内未主动与agent互动
- 用户情感产生较大波动
其中，情感波动定义为当前情绪向量与上一平滑情绪向量在 V-A 空间中的欧氏距离：$$\Delta d = \sqrt{(V_t - V_{t-1})² + (A_t - A_{t-1})²}$$
当$\Delta d \ge 0.45$时，则认为用户情绪产生较大波动。
无论是哪一种触发原因，模型都将结合多模态情感分析模型近3次计算的valence和arousal主动回应用户。
触发主动回应后，该机制进入120s的冷却期，冷却期内无法再次触发主动回应，直到冷却期结束。若两种触发条件同时满足，则只会触发一次主动回应，并统一进入冷却期。
