# 软著申请流程、材料


## 单人申请材料

- [ ] 申请表（单面打印，签名）
- [ ] 源码文档（单面打印）
- [ ] 软件设计文档或者使用说明文档
- [ ] 个人身份证复印件（正反面都要复印）

需要验证上海大学的著作权身份，软著中心将发送验证码给科技处的老师。上海大学学生若要获取验证码，请致电上海大学科技处（021-6613 6228，行政楼 508A 室）获取。

## 软著申请
1.审批表填写与审核
填写《上海大学申请软件著作权审批表》，审批表可在科研管理部网站-下载专区-理工-知识产权登记审批表（专利、软著及其他类型知识产权）中下载。由主要开发人（教职工）签字，将填好信息的WORD文档和签好字后扫描的PDF文档发送到科技合作处牛老师邮箱（award2004@shu.edu.cn）审核，并留好个人联系方式以便快速沟通。

若有合作单位（即著作权人非仅上海大学）的，需要严格依据双方签署的合同/协议/任务书中约定的知识产权条款及补充约定等划定权利所属人，并将相关文件（双章扫描件）一并发送到指定邮箱。同时，需签署软件著作权合作开发协议。

2.申请与用印
在中国版权保护中心系统中提交软件登记申请后，打印签章页（PDF，A4纵向打印），自行自行通过PIM提交申请。

提交知识产权相关文件用印时，须同步提交相关佐证文件，包括但不限于：

1.仅以上海大学为申请人申请知识产权时：审核后的披露（审批）表。

2.与合作单位共同申请知识产权时：审核后的披露（审批）表、在协议期内且有效的有明确知识产权约定的各类双章协议等。

其中：与合作单位共同申请知识产权时的软件著作权合作开发协议双章扫描件须发送至科研管理部科技合作处留档。

3.校内认定
在图书馆机构知识库中上传登记完成的软件著作权，附件中需要上传软著登记证书和校内审批表，以便学院初审及科研管理部复审。
